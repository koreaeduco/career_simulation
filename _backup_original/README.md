# 다음 장 · 진로 시뮬레이션 — 로컬 프로젝트

이 폴더는 공개된 웹사이트의 2026-10-26 배포본(버전 16)을 바탕으로 만든 **독립 실행용 복사본**입니다. 게임 화면과 데이터는 HTML·CSS·JavaScript 파일로 구성되어 있어 별도 게임 서버나 데이터베이스 없이 VS Code의 Live Server로 실행할 수 있습니다.

## 처음 실행하기

1. VS Code를 열고 **파일 → 폴더 열기**에서 이 폴더를 선택합니다.
2. VS Code의 **확장** 메뉴에서 **Live Server**를 설치합니다. 이미 설치했다면 건너뜁니다.
3. 왼쪽 파일 목록에서 **index.html**을 마우스 오른쪽 버튼으로 누르고 **Open with Live Server**를 선택합니다. 화면 오른쪽 아래에 **Go Live**가 보이면 그 버튼을 눌러도 됩니다.
4. 열린 브라우저에서 게임을 확인합니다. 주소는 보통 `http://127.0.0.1:5500/`처럼 표시되며, 설정에 따라 포트 번호는 달라질 수 있습니다.

파일을 수정하고 **Ctrl+S**로 저장하면 Live Server가 브라우저를 다시 불러옵니다. 바뀐 화면이 보이지 않으면 브라우저에서 **Ctrl+Shift+R**로 새로고침하세요.

## 주로 수정할 파일

| 바꾸고 싶은 것 | 먼저 볼 파일 |
| --- | --- |
| 화면 색, 글자, 배치 | `theme-v3.css`, `experience-v13.css` |
| 일상 선택 사건의 문장과 선택지 | `daily-choices.js`, `experience-v13.js` |
| 계열별 역할·전용 사건 | `role-events-v7.js` |
| 직업의 실제 업무·자료 | `career-source-v12.js`, `careers-v12.js` |
| 수강신청 과목·순서 | `curriculum-v5.js`, `registration-v9.js` |
| 화면에 어떤 파일을 불러오는지 | `index.html` |

이 게임은 기능을 여러 버전에 걸쳐 확장한 형태입니다. 같은 이름의 기능이 여러 파일에 있으면 **나중에 불러온 파일의 내용이 우선**할 수 있습니다. 처음에는 문구·색상처럼 작은 부분부터 수정하고, 수정 전에 폴더를 복사해 백업해 두는 것을 권장합니다.

## 알아둘 점

- 이 폴더의 코드를 수정해도 **공개 웹사이트는 자동으로 바뀌지 않습니다.** 온라인 반영에는 별도 배포가 필요합니다.
- 게임 진행 기록은 실행 중인 **각 브라우저의 로컬 저장 공간**에 남습니다. 공개 웹사이트와 이 로컬 프로젝트의 기록은 서로 연결되지 않습니다. 브라우저 데이터 삭제나 게스트 모드 종료 시 기록이 사라질 수 있습니다.
- 폰트 하나를 인터넷에서 불러옵니다. 인터넷이 없어도 기본 글꼴로 게임을 실행할 수 있지만 글자 모양은 달라질 수 있습니다.
- `index.html`과 나머지 파일을 같은 폴더에 두어야 합니다. Live Server는 이 폴더 자체를 열어 실행하세요.
